# Vatsal Maurya — research website

Source for https://anonycoderama.github.io

This is a Quarto research website designed around stable project pages. Research projects can move from work-in-progress to manuscript, peer review, and publication without changing their project URL.

## Local preview

```bash
quarto preview
```

## Publish

Pushes to `main` trigger `.github/workflows/publish.yml`, which renders the site and publishes it to the `gh-pages` branch.
